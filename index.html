02 — FOUNDATIONCHOOSE YOUR TYPE

Same JSON syntax.
Different superpowers.

{ }

JSON

TEXT REPRESENTATION
  • Preserves input text and whitespace
  • Preserves object key order
  • Reparses for processing
  • Useful when input fidelity matters
VS
{ B }

JSONB

OUR FOCUS
  • Stored in decomposed binary form
  • Supports indexing and containment
  • Does not preserve key order / duplicates
  • Usually preferable for querying

Both types validate JSON. JSONB has processing and indexing benefits, with conversion overhead at input.

08 — ADVANCED SEARCHSQL / JSON PATH

When a key isn't enough,
follow a pattern.

01@? / PATH EXISTS

Find products tagged gaming

SELECT data ->> 'name'
FROM catalog
WHERE data @?
  '$.tags[*] ? (@ == "gaming")';
RESULT Pulse X · Forge 16
02@@ / PREDICATE CHECK

Find products above $1,000

SELECT data ->> 'name'
FROM catalog
WHERE data @@ '$.price > 1000';
RESULT Atlas Pro 14 · Forge 16
✳
Why it matters: JSONPath can filter inside arrays and traverse irregular documents. @? asks whether a path yields a match; @@ evaluates a predicate.
09 — ANALYTICSTURN ARRAYS INTO ROWS

top_tags.sqlSQL
SELECT tag, COUNT(*) AS uses
FROM catalog c
CROSS JOIN LATERAL
  jsonb_array_elements_text(

GROUP BY tag
ORDER BY uses DESC, tag;

10 — PERFORMANCEINDEXING STRATEGY

Flexible shouldn't mean
impossible to scale.

A / GENERAL PURPOSE

GIN jsonb_ops

CREATE INDEX cat_gin
ON catalog USING GIN (data);

Supports @>, ?, ?|, ?& and JSONPath search operators.

B / CONTAINMENT OPTIMIZED

GIN jsonb_path_ops

CREATE INDEX cat_path
ON catalog USING GIN
  (data jsonb_path_ops);

Focused on @>, @?, @@ — not key existence ?.

C / SCALAR FILTERING

B-tree expression index

CREATE INDEX cat_price
ON catalog
  (((data->>'price')::numeric));

Useful for ordered numeric comparisons on extracted scalar values.

Index selection depends on predicates, data distribution, planner estimates, and write/storage costs.

12 — GOOD ENGINEERINGTHINK BEFORE YOU QUERY

Four pitfalls.
Zero excuses.

01

Text ≠ number

->> returns text. Use an explicit safe cast when comparing quantities.

≠
02

Existence is not recursive

? searches top-level keys/array elements. For deep search, navigate or use JSONPath.

⌄
03

Indexes have a cost

GIN helps reads, but consumes storage and adds write maintenance.

↔
04

Not everything belongs in JSONB

Keep stable identifiers, constraints, and heavily joined relationships relational.
